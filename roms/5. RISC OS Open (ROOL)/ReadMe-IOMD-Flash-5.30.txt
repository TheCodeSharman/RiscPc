RISC OS Open: IOMDHAL Stable Release 5.30 (flash programmer)
============================================================

This is the IOMDHAL stable release 5.30 ROM image, it can be programmed
into the flash memory on a Kinetic processor upgrade in your Risc PC
using the supplied programmer, !KinPrg.

If your Kinetic doesn't have flash memory, or you don't have a Kinetic,
this stable release can be purchased in ROM form from the ROOL web site:

  https://www.riscosopen.org/content/sales

If you aren't sure about programming this new ROM into your Kinetic, please
consider using the "softload" version of this stable build. This can be
downloaded from the ROOL web site:

  https://www.riscosopen.org/content/downloads/riscpc
